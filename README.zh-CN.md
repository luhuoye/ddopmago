# ꅇꂷꇬ (com.ddopmago)
彝文(规范彝文/凉山) ⇄ 普通话 词句库检索 + 内置彝文键盘 + 收藏 + 做题。

## 打包 APK（GitHub）
1. 新建 **私有** 仓库，把本目录全部文件(含隐藏的 .github)推送到 main 分支。词典分卷已内置在 `app/src/main/assets/dict/`（dict.zip.00、dict.zip.01，每卷 ≤24MB，内含 彝汉英常用词词汇(2008) 的 mdx 与 mdd）。
2. Actions → Build APK 自动运行，下载 Artifacts 里的 `ddopmago-apk`。
3. 安装后第一次打开，软件把分卷合并解压到应用目录，并放进「字典 → 2008词典」。

## 功能
- 所有文字输入只用内置键盘（不弹系统键盘）：⇄ 键切换 彝文拼音(候选+1165字表) / 中文(字表+联想) / 字母。
- 所有彝文逐字标注拼音（拼音题的题干除外）。
- 翻译：彝⇄中 词句检索（例句 + 词典词条），可收藏。
- 字典：词句分类、彝汉词典（《规范彝文词典》1005 条带释义例词）、词库（《彝文词库》5.7万词，按拼音/彝文查）、音节表。
- 做题：选择、判断、填空、翻译、拼音题、混合、收藏题；考试满分100（选择8×3+填空5×4+判断8×2+翻译4×5+拼音10×2）。

## 说明
- 翻译为《彝语900句》942 个句子的相似度检索，不是机器翻译；词库外的内容查不到。
- 彝文显示依赖系统自带 Noto Sans Yi 字体，个别国产 ROM 如显示方块，需自行加入字体文件。
- 词库来自《彝语900句》(版权属原出版社/作者)，仓库请保持私有，公开发布前需取得授权。
- 试卷/资料数据：`python3 tools/build_papers.py <中考资料目录> <高考加试目录>`。
- 重新生成数据：先 `python3 tools/build_corpus.py book.md`，再 `python3 tools/build_dict.py 词库.txt dictraw.txt app/src/main/assets/sentences.json`。
- 彝学研究网在线词典(yixueyanjiu.com)禁止自动抓取，未导入；如获得作者授权的数据，按 dict.json 格式 [["彝文词","中文释义"],...] 追加即可。
